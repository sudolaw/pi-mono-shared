# pi-mono-shared

Public snapshot of selected projects from pi_mono, a private collection of independent
projects (one per top-level directory). Each project here is a copy of that project's
files on pi_mono's `main`; development happens there and is copied over with
[`sync.sh`](sync.sh).

## Projects

- [mcp_multi_player](mcp_multi_player/): two-player tower defense & offense game that AI agents play over MCP, watched in the browser
- [nudge](nudge/): Android app (Flutter) for routines with half-life nagging, daily promises, time goals and location alarms
